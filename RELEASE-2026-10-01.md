# BiteCode Control — Reliable Upgrade Release

This package is based on the supplied current BiteCode Control project. Existing features and configuration files are preserved.

## Included
- Feedback center for participants, judges, mentors and volunteers; admin review/export.
- Participant academic fields: enrollment, department, group/section and year.
- Attendance filtering and CSV/PDF-print reporting by department/group/year.
- Automatic Winner/Runner-up certificate detection from submitted evaluation rankings.
- Event-wide automatic certificate issuing.
- Compiler copy/cut/paste and context-menu deterrence in the browser editor.
- Session-based authentication with an additional per-tab guard.
- Notification integration for feedback and existing operational events.
- Responsive logged-in workspace scrolling.

## Environment
No `.env` file is included in this package. Keep the existing environment configuration already used by your deployment/local setup. Do not commit secrets.

## Git
The package intentionally does not contain `.git` or `node_modules`. Replace/update the project files in your existing Git working tree, verify the existing `.env` remains in place locally, then run `git status`, `git diff`, and `git push origin main`.

## Validation
All backend JavaScript files pass `node --check`. Frontend production build could not be executed in this environment because dependency installation was unavailable/timed out; run `npm install`/`npm ci` and `npm run build --prefix frontend` locally before pushing if your workflow requires a local build check.
