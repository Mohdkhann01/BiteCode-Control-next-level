# BiteCode Control maintenance upgrade — 2026-10-10

## Changes in this patch

- Finance payment page now selects its sidebar from the authenticated user's role rather than forcing the full admin sidebar. Finance users remain on the payment workspace; route guards and backend permission checks remain in place.
- AI status now distinguishes event access from provider readiness. The participant AI toggle remains driven by the event setting, while the UI can display service availability correctly when `OPENROUTER_API_KEY` is missing.
- Cloudinary configuration status is included in the system health response and admin operations health panel instead of reporting upload storage as always operational.
- Cloudinary image uploads continue to use backend credentials, memory-backed uploads, JPEG/PNG/WebP allowlisting, and an 8 MB limit. Upload validation errors return client errors rather than generic server errors.
- Improved native select-option contrast, keyboard focus visibility, and small-screen AI/payment layouts.
- `.gitignore` now excludes environment files while allowing `.env.example` templates.

## Required Render environment variables

Set these in the backend service's Render Environment settings (not in frontend variables):

- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET`

For AI, also confirm `OPENROUTER_API_KEY` is set. For compiler execution, confirm `JUDGE0_URL` and, if required by your Judge0 provider, `JUDGE0_AUTH_TOKEN` are set.

After changing environment variables, restart/redeploy the backend service. Do not commit real `.env` files or credentials.

## Verification performed in this environment

- `node --check` passed for every backend JavaScript file.
- Babel parser syntax checks passed for `frontend/src/main.jsx`, `frontend/src/AIAssistant.jsx`, and `frontend/src/AntiCheatGuard.jsx`.
